01何のための型か

1枚に載せるのは見出し＋1つの部品＋一文だけ。部品はカード・手順・対比・引用・数字・図のいずれかひとつ。枚数が増えても崩れないことを優先しているので、代わりに1枚あたりの情報量は絞られる。

迷ったら次の一点だけを見る：その1枚は、見出しと1つの部品と一文で言い切れるか。
言い切れないなら、足すのではなく2枚に割る。

02骨格

16:9固定のステージを1つ作り、その中をコンテナクエリ単位（cqw / cqh）だけで組む。これで画面サイズが変わっても比率が崩れない。rem や px を混ぜた瞬間に崩れるので混ぜない。

.deck{
  width: min(100vw, 177.78vh);   /* 16:9を維持 */
  height: min(56.25vw, 100vh);
  container-type: size;          /* これがcqwの基準になる */
  overflow: hidden;              /* 外枠に角丸はつけない */
  background:
    radial-gradient(80cqw 62cqw at 88% 4%, rgba(206,124,124,.055), transparent 62%),
    radial-gradient(72cqw 52cqw at 4% 98%, rgba(217,130,43,.05), transparent 62%),
    var(--paper);             /* 混白+ごく薄い2枚のにじみ */
}
.slide{
  position: absolute; inset: 0;
  padding: 5.6cqw 6.2cqw 12.4cqw;  /* 下だけ広い = フッターの逃げ */
  display: flex; flex-direction: column;
}

1枚の中身は上から h2（見出し）→ .body（flex:1 で残りを埋めて中央寄せ）→ .takeaway（下部中央の一文）。.cite と .deckfoot は絶対配置で、全ページ同じ位置に出る。

03色

地は純白にしない。地とカードの2段だけで温度差をつくる。ダークモードには対応しない — 会場のプロジェクタで白地に出す前提なので prefers-color-scheme は書かない。

--paper

#F8F6F2

地。純白にしない。ここが温かいだけで印象が決まる。

--card

#FFFFFF

カード面。地との差はこの一段だけで足りる。

--ink

#26333F

本文・見出し。黒ではなく紺寄り。

--ink-2

#4E5F60

説明文・補足。カード内の本文はすべてこれ。

--ink-3

#8B98A4

ラベル・出典・ページ番号。読ませない文字。

--line

#E6E1D9

罫線。フッターと .points の区切りだけ。

--fill

#F1ECE4

図の面。地とカードの中間の温度。図に寒色の面を置かない。

--accent

#D9822B

見出しの縦罫、カード左罫、アイコン、締めの一行。

--neg

#DC4A4A

Before側のみ。それ以外では絶対に使わない。

--pos

#12776A

After側のみ。同上。

オレンジは1枚に1役だけ。見出しの縦罫は全ページ共通なので数に入れない。そのうえで「タイトルの一句」「カード見出し」「単位」「締めの一行」のどれかひとつに絞る。2つ以上に振ると、どこを見ればいいか分からなくなる。

04文字

2書体だけ。和文の見出しは Zen Kaku Gothic New、欧文と数字は Lato。本文の和文は Noto Sans JP に落ちる。font-family:"Lato","Noto Sans JP",… の順で書くと、欧文だけLatoになる。

締めの一行.close .l34.4cqw900オレンジ。ここだけ900を使う

05影のつくり方

影は1種類だけ（drop-shadow 系、強めない）。強い影を足すと絵の質感が消える。同じ台紙の中で「影あり」と「影なし」を混在させない — 役割を変えると、意図が曖昧になって伝わらなくなる。

種類使う値使う場面
影つきfilter: drop-shadow(0 4px 12px rgba(38,51,63,.12)).pcard / .quote / .filled、地の中で選択肢を示すとき
影なしborder-radius: 1.5cqw（角丸のみ）.step / .stat / .chip、単位・見出し・数字

06コンポーネント

見本は sample.html。各ページが、そのページで説明しているコンポーネントそのもので組んである。以下はその実例に、対応クラスをあてたもの。

.pcard.four

声の大きい人

声の大きさでの決定はただの「抑圧」

エスカレーション

「ユーザーから遠い人」に決めてもらう

ユーザーテスト

どのユーザーに聞くかで結論が変わる

ビジョン

自分の都合に合わせて解釈できてしまう

要約カード。3〜4列。本文は40〜50字まで。

.steps

STEP 01
誰の行動が変わったか
STEP 02
どの指標に現れる
STEP 03
事業にどう効くか

手順・時系列。番号に沿って3〜4個、1見出し10字以内。

.bar（Before / After）

Before

どちらが正しいか？

After

仮説をどう検証するか？

左右2軸の対比。左右で行トーンをそろえる。色は --neg / --pos のみ。

.quote

Everyone is right — partially.

引用。静かな「まとめ」に使う。2行以内。

.highlight

検証は実行されなかった。
皆はそれを受け入れた。

地に直書きの強めの一行。最大24cqw、枠も影もつけない。

.cclose

わかり合えないまま、一緒に進む

章末だけに使う締めの一行。オレンジの枠のみ。

クラス系統概要
.s-title表紙全体で1枚だけ。.metaback に開催情報
.s-section章区切り独立するときだけ、見出し・罫はなく番号だけ置く
.pcard.filled選択の要約本文40字まで、アイコンは寒色パステル
.pcard.three3列3列並ぶので本文50字以内
.stats数字と単位3つまで、単位はオレンジ、数字は ink のまま
.refbox出典参照16字以内、返信元・識別子を添える
.figure + .figcaption図つき図は塗りつぶしカードの中、キャプションは左に入れる

写真やイラストを扱う図は、白カードを使わない。縦横比 1:1 前後の枠で作って中央に置き、はみ出しは許さない。

07図の描き方

図はSVGで描く。形は自由でよいが、色は4つ、線は2種、破線は1種までにやさしく絞る。増やした瞬間に、図はページの中で一番迷いやすい要素になる。

.g-ink    { fill: none; stroke: var(--ink);    stroke-width: 2; }
.g-fill   { fill: var(--ink);   fill-opacity: .08; }
.g-accent { fill: var(--accent); }
.g-pos    { fill: none; stroke: var(--pos); stroke-width: 2.4; }
.g-neg    { fill: none; stroke: var(--neg); stroke-width: 2.4; stroke-dasharray: 4 3; }

置き方は2つ。

パターン使い方使う場面
.figrow + .figcard左に説明、右62%に白カードの図図に意味の補足が要るとき
.rightUI地に直書き、最大74cqw、枠も影もなし図だけで読み取れるとき

やる

  • 文字はラベル（15px）と補助（13px）の2段だけ
  • 線幅は2.4（実線）と2（基本）の2種だけ
  • 細線は0.7〜1pxで罫線用途に限定
  • .fill / .accent は塗り分けの役割をきっちり分ける

やらない

  • 矢印を3つ以上置く
  • 図の中に説明文を書き込む（左の .body へ出す）
  • 図の中だけ余白を持たせる（カードだけ伸びて図が縮む）
  • 色を4種以上に増やす

08ルール

やる

  • 枠は16:9のみ
  • 色は同一トーンで統一する（数を優先しない）
  • 1枚には見出し＋部品1つ＋一文まで
  • 言い切れない情報は次の1枚に送る
  • 差し替えても崩れない、はみ出しは禁止

やらない

  • ダークモード対応（プロジェクタ前提）
  • オレンジを1枚に2箇所以上使う
  • 赤・緑（--neg/--pos）をBefore/After以外で使う
  • 同じ1枠で影ありカードと影なしカードを混ぜる
  • カードを5枚以上に増やす（4枚が上限）

091枚ぶんの雛形

<section class="slide">
  <h2>見出し</h2>
  <div class="body">
    <!-- 部品ひとつ：cards / steps / bar / quote / stats / 図 -->
  </div>
  <p class="takeaway reveal" style="--i:1">締めの一文。強調は<b>で1語</b></p>
  <p class="cite">出典行、これ</p>
</section>

登場アニメーションは class="reveal" と style="--i:N" だけ。全要素に0.14秒ずつ遅れて出る。動きはこれ以上増やさない。
